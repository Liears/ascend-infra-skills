01靶子：为什么打 SparseFlashMla

对引擎 393 个稳态 decode 步做算子级 profile（kernel_details.csv），逐算子拆解 SCALAR / FIXPIPE / MAC 占比后，aclnnSparseFlashMla 是全模型最大的单项固定开销来源：每步调用 18.6 次、合计 3.17 ms，占整步 31.6 ms 的 8.3%——且它的矩阵核时间中真正做乘加（MAC）的只有 12.7%。

第一笔账：170 µs 里约 99% 是固定开销。它每次调用只需搬运 0.65 MB（640 条选中 KV × 512 维 × 2B，全速带宽下 <1 µs）、计算 63 MFLOP（6 token × 8 head × 640 × 512 × 2，<1 µs）。 需求合计不足 2 µs，实测 170 µs——开销不在数据量，在路径本身。
构造独立微基准时，aclnn 参数校验逐条暴露了 A2/A3 的专属限制（EZ1001 原文）： ori_topk 只能为 0 · cmp_ratio 必须为 128（"HCA without cmp_sparse_indices"）· cmp_mask_mode 必须为 3 · cmp_residual_kv 必须提供。 —— 该算子按 A5 的通用稀疏路径设计，A2 被锁进参数面更窄的 HCA 兼容路径。这与其 43%/56% 的 SCALAR/FIXPIPE 形态互相印证。

03同口径对决：NPU graph 内的设备时间

这是唯一有效的比较口径——引擎里这些调用运行在 ACL 图内，host 派发早已被摊掉。官方内核的 170 µs 是设备执行时间，不是派发开销；把它和 PyTorch 组合放进同一张 NPU graph 里重放，才是同类相搏。

04胜出的实现：29 行，无自定义内核

完整语义覆盖：paged KV 按全局行号 gather、−1 无效列掩码、attention sink、逐请求索引映射。胜负手只有一个——bmm 的形状 [T,H,D] @ [T,D,W] 让 8 个 head 共享同一份已 gather 的 KV 而零复制；朴素 einsum 的 fp32 广播复制 8 份 KV，就是 493 µs 与 144 µs 的全部差别。

def torch_sparse_mla(q, kv_cache, sparse_indices, req_to_token, sinks=None, scale=None):
    # q: [T,H,D] TND · kv_cache: [NB,BLOCK,1,D] paged · sparse_indices: [R,W] 全局行号（-1 无效）
    T, H, D = q.shape
    flat = kv_cache.reshape(-1, D)
    idx  = sparse_indices.index_select(0, req_to_token)      # [T,W]
    valid = idx >= 0
    kvs  = flat.index_select(0, idx.clamp(min=0).reshape(-1)).reshape(T, -1, D)
    s    = torch.bmm(q, kvs.transpose(1, 2)) * scale         # [T,H,D]@[T,D,W] → [T,H,W]，无复制
    s    = s.masked_fill(~valid[:, None, :], -1e4)           # -inf 会使全 -1 的 padded 行 softmax 成 NaN
    if sinks is not None: s = s + sinks[None, :, None]
    a    = torch.softmax(s, dim=-1)
    return torch.bmm(a, kvs)                            # [T,H,W]@[T,W,D] → [T,H,D]

06三条教训（每条都有实验背书）

教训 01

图外测耗时是陷阱

Triton-Ascend 单次派发 ≈ 150 µs：split-KV 两阶段版 391 µs ≈ 2× 单内核 183.5 µs，差值正好是第二次派发。任何候选必须在 NPU graph 重放里评估——那才是引擎的口径。

教训 02

官方内核慢的不是派发，是路径

170 µs 产生于引擎 ACL 图内（派发已摊掉），是 HCA 兼容路径本身的设备执行成本。十个各自高效通用 kernel，胜过一个跑在坏路径上的融合内核。

教训 03

形状选择值 3.4 倍

einsum 的 fp32 广播把共享 KV 复制 8 份（493 µs）；bmm 形状 [T,H,D]@[T,D,W] 零复制（144 µs）。一行形状改动，3.4×——先审形状，再写内核。
